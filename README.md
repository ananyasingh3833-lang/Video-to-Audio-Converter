# Video-to-Audio-Converter

I chose this project because extracting audio from a video is a useful and practical task. It also gives me an opportunity to learn about Python libraries, file handling, user input, and multimedia processing.

Why I Am Creating This Project?
-> I am creating this project to learn how Python can be used for real-world applications, especially for handling and processing multimedia files. The main purpose of my project is to convert a video file into an audio file, such as MP3.
